How analog sound becomes digital data — step by step

The Original Analog Signal

Real-world sounds (voice, music) are continuous waves — they can have any value at any instant. This is what a microphone captures.

Analog waveform (continuous)
Problem: Computers can't store "any value at any instant" — they need discrete numbers. That's exactly what PCM solves.
1
Step 1 — Sampling

We "take a snapshot" of the wave's height at regular time intervals. The number of snapshots per second is the sample rate.

8 samples/sec (drag to change)

Sample moments
Nyquist Rule: To capture a sound accurately, sample at least 2× its highest frequency. Human hearing tops out at ~20 kHz, so CDs use 44,100 samples/sec (44.1 kHz). Try dragging the slider above — fewer samples = less accurate reconstruction.
2
Step 2 — Quantization

Each sample is rounded to the nearest level on a fixed grid. The number of levels depends on bit depth. More bits = more levels = more accurate.

3-bit = 8 levels
Analog wave
Quantized (rounded) value
Quantization error
Quantization Error is the gap between the real value and the rounded value — it sounds like faint background hiss. More bits = smaller error = cleaner audio.
CD audio uses 16-bit (65,536 levels). Studio recordings use 24-bit.
3
Step 3 — Encoding (Quantized Level → Binary Number)

After quantization we have a level number (e.g. "level 5 out of 8"). Encoding simply converts that integer to binary. Each sample gets the same fixed number of bits (= bit depth). Click any sample below to see exactly how its level maps to bits.

Why binary? Computers store everything as 0s and 1s (voltage off/on). A 3-bit number needs 3 wires / storage cells. A 16-bit sample needs 16. The bit stream is exactly what lives inside a .wav file — no compression, no tricks.

Real CD audio: 44,100 Hz × 16 bits × 2 channels = 1,411,200 bits/sec (~1.4 Mbps). MP3 compresses this same data down to ~128 kbps — that's the tradeoff between quality and file size.
